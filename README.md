# redux-like-middleware-for-usereducer

Redux-style middleware for React's `useReducer` hook, packaged as a small, typed, publishable library.

## Features

- Works with React 18 and 19
- Ships ESM, CommonJS, sourcemaps, and TypeScript declarations
- Supports middleware before dispatch and after state updates
- Keeps the original lightweight API, including the legacy positional signature
- Includes linting, typechecking, tests, and CI-ready workflows

## Installation

```bash
npm install redux-like-middleware-for-usereducer react
```

## Quick start

```tsx
import { useReducerWithMiddleware } from "redux-like-middleware-for-usereducer";

const reducer = (state, action) => {
  switch (action.type) {
    case "increment":
      return { count: state.count + 1 };
    default:
      return state;
  }
};

const beforeDispatch = (action, state) => {
  console.log("before", action, state);
};

const afterDispatch = (action, state) => {
  console.log("after", action, state);
};

function Counter() {
  const [state, dispatch] = useReducerWithMiddleware(reducer, { count: 0 }, {
    beforeDispatch: [beforeDispatch],
    afterDispatch: [afterDispatch],
  });

  return (
    <button onClick={() => dispatch({ type: "increment" })}>
      {state.count}
    </button>
  );
}
```

## API

### `useReducerWithMiddleware(reducer, initialArg, options)`

Returns the same tuple as `useReducer`: `[state, dispatch]`.

#### `options.beforeDispatch`

An array of middleware functions that run synchronously before the reducer dispatches. Each middleware receives `(action, currentState)`.

#### `options.afterDispatch`

An array of middleware functions that run after React applies the next state. Each middleware receives `(action, nextState)`.

#### `options.initializer`

Optional lazy initializer matching the `useReducer` initializer pattern.

### Legacy signature

The original positional form still works:

```ts
useReducerWithMiddleware(reducer, initialState, [beforeDispatch], [afterDispatch]);
```
